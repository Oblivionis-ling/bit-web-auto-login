# BIT-Web Auto Login v1.4.0 实施验证

日期：2026-09-19

## 交付物

面向普通用户的入口为：

```text
BITWebAutoLogin-Setup-v1.4.0-win-x64.exe
```

用户只需从 GitHub Releases 下载并运行这一个文件。EXE 内嵌完整的 self-contained Release ZIP，校验版本、manifest、文件大小和 SHA-256 后，从独立临时目录打开现有 WPF Manager。关闭 Manager 后，Bootstrapper 会清理这次展开的临时目录。

Release 仍需同时上传 ZIP 与其 SHA-256，供已安装 Manager 的在线更新链路使用；普通用户首次使用不需要下载 ZIP。

## 可重复构建

从仓库根目录运行：

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\build\Build-Release.ps1
```

构建脚本使用 `manager/Directory.Build.props` 与 `settings.json` 的 canonical version，依次发布 Manager、Updater、版本化 ZIP 和内嵌该 ZIP 的 Bootstrapper，并生成两个 SHA-256 文件及 `build-result.json`。
