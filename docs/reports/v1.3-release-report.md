## 9. 已知非阻塞项

1. GitHub 大文件下载在部分网络/代理节点可能连接重置或超时；当前失败边界安全，但没有断点续传。
2. helper handoff 后 `%TEMP%` 可能保留 update workspace；本次更新后也观察到新的残留目录，不影响安装正确性。
3. 当前未做 Authenticode 签名，Windows 可能显示 SmartScreen / Unknown publisher。

以上均进入后续 `v1.3.x` backlog，不在 Stable 发布前修改 UpdateService 或清理逻辑。
